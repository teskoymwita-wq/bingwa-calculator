BINGWA CALCULATOR — ANDROID PROJECT
Hii ni project ya Android Studio ya calculator ya offline pekee.

Muhimu:
- Hii ni source project, si APK iliyojengwa.
- Android SDK/Gradle build environment haipatikani kwenye mazingira haya, kwa hiyo siwezi kusema APK imejengwa au kupimwa.
- Fungua folder hii kwa Android Studio kwenye kompyuta yenye Android SDK, kisha Build > Build APK(s).
- Calculator yenyewe inafanya kazi bila internet; hakuna internet permission.
